## Manage company internship postings
Companies manage postings on **Internship Postings** at `/company/jobs`. To start a role, select **Post New Role**, complete its title, description, skills, location, work mode, duration, stipend, eligibility, and deadline, then create the draft and submit it for review. Review its moderation status. Edit an existing posting from its actions; updates may require review before becoming visible.

## Close a posting
To stop accepting applications for a published role, select **Close Role** on that posting in **Internship Postings**. Confirm the intended posting before closing it. A closed or expired internship is not an active opportunity; review applicants and communicate any final status changes from the applicant workflow.

## Check posting status
Open **Internship Postings** (also called My Internships) to view the current status of each posting, including active, pending, closed, or expired. Use this page to review applicants and confirm that each internship reflects the correct publishing state.
