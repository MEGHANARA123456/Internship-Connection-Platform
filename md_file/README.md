# Internship Connection Platform

InternSphere connects students with internship opportunities and employers. Students can maintain profiles with education details, verified skill badges, GitHub and LeetCode links, and resumes; discover and apply to roles; and track application progress. Employers can post and manage roles, review applicants, message candidates, and schedule interviews. Administrators manage users, company verification, moderation, and platform analytics.

The supported student experience includes job matching and recommended internships. University details remain part of student profiles and resume education history. College placement reporting and faculty or mentor endorsement workflows are not supported features.

See [the backend and system architecture reference](./BACKEND_AND_SYSTEM_ARCHITECTURE.md) and [frontend integration notes](../frontend/INTEGRATION_NOTES.md) for implementation details.
